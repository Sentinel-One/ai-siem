# Contributors 🎉

AI-SIEM exists because people took the time to write a parser for a log
source nobody else had covered, build the dashboard they wished they had,
tune a detection until it stopped crying wolf, or fix a typo someone else
would have walked past. **Thank you.** Every entry below is a merged
contribution that someone, somewhere, is using to see their environment more
clearly.

## Community recognition

We celebrate contributors every quarter:

| Award | Goes to |
| ----- | ------- |
| 🏆 **Top Contributor** | The most valuable merged work of the quarter |
| 💡 **Most Interesting Use-Case** | The cleverest or most unexpected application of the library |
| 📊 **Best Dashboard** | The dashboard that made data easiest to understand |

Past winners will be listed here. Every merged PR counts, whatever its size.

## Join them

First contribution? Wonderful. A new parser, a sharper detection, a clearer
README and a fixed typo all count equally here. Start with
[CONTRIBUTING.md](CONTRIBUTING.md), and if you're unsure where to begin, open
a [content request](.github/ISSUE_TEMPLATE/content_request.md) or ask in an
issue. We'll help you land it.

*Missing from this list, or listed incorrectly? Open a PR or an issue and
we'll fix it right away. This list is generated from commit history, so
co-authors and anyone who contributed under a different name may need adding.*
